# CLIPSMALS

**KlipViral AI** — Ubah video YouTube panjang menjadi 10+ klip pendek viral-ready untuk TikTok, YouTube Shorts, dan Instagram Reels secara otomatis. 100% lokal, tanpa API key, tanpa cloud.

## Tech Stack
- Next.js 15 + React 19 + TypeScript
- Tailwind CSS 3.4 (Material Design 3 Dark Theme)
- FFmpeg + yt-dlp (local binary)

## Features
- Full pipeline: URL → transkrip → AI scoring → download → klip otomatis
- 5 template caption kinetic typography
- 3 aspect ratio (9:16, 1:1, 16:9)
- Live preview & clip editor
- Download MP4 & export SRT

## Setup
```bash
# Windows
setup.bat
# atau manual
npm install
npm run dev
```
